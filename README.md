# Random Joke Generator 😂

A simple web application that fetches and displays random jokes using an external API.

## Features

- 🎲 Get random jokes with one click
- 🎨 Beautiful gradient UI design
- ⚡ Fast and responsive
- 🔄 Automatically loads a joke on page load
- 🌐 Uses the [Official Joke API](https://official-joke-api.appspot.com/)

## How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Click the "Get New Joke" button to fetch a random joke
4. Enjoy! 😄
